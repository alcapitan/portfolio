## 🛠️ Stack Technique

Pour ce projet, j'ai choisi une stack moderne, apprise à mon initiative et avec pour priorité les bonnes pratiques des entreprises (DevOps, CI/CD, Containerisation).

### Front-end
* **Framework :** React et Vite.
* **Gestionnaire de paquets :** Pnpm.
* **UI :** TailwindCSS + DaisyUI.

### DevOps & Infrastructure
* **Containerisation :** Docker.
* **Hébergement :** VPS personnel.
* **CI/CD :** Github Actions (validation et déploiement).

## 🚀 Installation Locale
Si vous souhaitez lancer le projet en local pour y jeter un œil :

### Avec pnpm

```bash
# Cloner le dépôt
git clone https://github.com/alcapitan/portfolio.git

# Aller dans le dossier
cd portfolio

# Installer les dépendances
pnpm install

# Lancer le serveur de développement
pnpm dev
```

### Avec docker

```bash
# Build de l'image
docker build -t portfolio .

# Lancer le conteneur
docker run -p 3000:80 portfolio
```
